# Сайт ФРСРК: правила проекта

Официальный сайт Федерации роуп скиппинга (спортивной скакалки) Республики Крым. Владелец проекта пишет по-русски и не программист: объясняй просто, давай точные пути к файлам.

## Что нельзя нарушать

- **Не выдумывать факты.** ФИО, даты, адреса, телефоны, номера приказов, цифры берутся только из документов федерации (`seed-assets/documents/`, сканы Устава и приказов) или из данных владельца. Нет данных: блок не выводится или пишется «в разработке».
- **Никаких демо-данных и заглушек** в публичной части. Пустой раздел говорит правду одной фразой.
- **Название федерации строго по Уставу:** Общественная организация «Федерация роуп скиппинга (спортивной скакалки) Республики Крым», сокращённо ОО «ФРСРК» (на сайте ФРСРК).
- **Файлы не хранятся в сайте.** Документы, музыка, фото и видео только в S3 через админку. В `public/` лежит лишь оформление (логотип, значки, фоны шапок).
- **Персональные данные детей** (фото, списки) публикует владелец. Списки сборной и приказы с фамилиями скрыты. Фотоархив опубликован по решению владельца, ответственность за согласия родителей на нём.
- **Новые изображения людей не генерировать.** Главное фото на первом экране утверждено владельцем (`seed-assets/source/hero.webp`). Иллюстрации без людей делаются через Codex (`codex exec`), реальные фото загружает федерация.
- Не менять герб и логотип. Подпись в подвале «Разработан и создан Данильченко Ю. Л.» сохранять.

## Тексты

## Технологии

Next.js 16, React 19, TypeScript strict, Payload CMS 3, PostgreSQL, S3, Docker. Node 24.

- Server Components по умолчанию, `"use client"` только для реальной интерактивности (навигация, карта, форма, cookie).
- Публичные страницы читают данные только через `src/lib/cms.ts`.
- Дизайн: `src/app/(frontend)/globals.css`. Токены цветов в `:root`. Шрифт Inter (пакет fontsource, без внешних запросов). Дизайн светлый и яркий, как в старой версии frsrk-2.0: белая шапка с волной флага, красная кнопка «Найти секцию», тонкие линии, вкладки внутри разделов.
- Доступность: зоны нажатия не меньше 44 px, видимый фокус, `prefers-reduced-motion`, контраст WCAG AA.

## Структура сайта

Меню: Главная, Календарь, Документы, Новости, Медиа, Участникам, О федерации, Контакты и красная кнопка «Найти секцию». Разделы «Документы», «Участникам» и «О федерации» устроены одинаково: слева пункты, справа содержимое (`src/components/section`). «Участникам»: Тренерам, Судьям, Родителям, Рейтинг спортсменов, Антидопинг. «О федерации»: О федерации, Руководство, Реквизиты, История. Правила вида спорта это текстовая страница внутри «Документов» с вкладками. Старые адреса (`/parents`, `/ranking`, `/education`, `/antidoping`) перенаправляются в `next.config.mjs`.

Рукописные надписи на флаге и полосах заголовков используют шрифт из переменной `--font-script` (Bad Script: тонкий рукописный шрифт с кириллицей, пакет fontsource).

## Порядок работы

1. Изменения минимальные и в рамках задачи.
2. После изменений: `npm run check` (типы, линтер, тесты, сборка). Без ошибок.
3. Изменения в `src/collections` и `src/globals` требуют новой миграции (см. README) и `npm run generate:types`.
4. Не менять `.env*` и существующие миграции без согласования.
5. Коммит только по просьбе владельца.
