# Сайт ФРСРК

Официальный сайт Федерации роуп скиппинга (спортивной скакалки) Республики Крым.

Сайт публичный, с админкой. Все файлы (документы, музыка, фото, видео) лежат в файловом хранилище S3, в самом сайте их нет.

## Из чего сделан

- Next.js 16 (App Router), React 19, TypeScript.
- Payload CMS 3 внутри того же приложения: админка на `/admin`, роли «Администратор» и «Редактор».
- PostgreSQL (Timeweb Cloud, управляемая база).
- S3 (Timeweb Cloud) для всех загруженных файлов. Без настроек S3 файлы кладутся в локальную папку `storage/`, но так можно только при разработке.
- Docker для запуска на Timeweb App Platform.

## Запуск на своём компьютере

Нужны Node.js 24 и PostgreSQL 15 или новее.

```bash
brew install node@24 postgresql@17
brew services start postgresql@17
createdb frsrk_v3

cp .env.example .env   # заполните DATABASE_URL, PAYLOAD_SECRET
npm install
npm run migrate        # создаёт таблицы
npm run seed           # загружает документы, музыку, тексты, данные
npm run dev            # http://localhost:3100
```

Пример локального `.env`:

```
NEXT_PUBLIC_SITE_URL=http://localhost:3100
DATABASE_URL=postgresql://localhost:5432/frsrk_v3
PAYLOAD_SECRET=любая-строка-не-короче-32-символов
```

Первый вход в админку: `http://localhost:3100/admin`, форма создаст администратора.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Сайт для разработки на порту 3100 |
| `npm run check` | Типы, линтер, тесты и сборка. Запускать перед отправкой на GitHub |
| `npm run migrate` | Применить миграции базы |
| `npm run migrate:create имя` | Создать миграцию после изменения коллекций (см. ниже) |
| `npm run seed` | Первичное наполнение (документы, музыка, тексты, данные) |
| `npm run seed:prod` | То же, но в боевую базу и хранилище. Читает `.env.prod` |
| `npm run images:optimize` | Подготовить картинки из `seed-assets/` |
| `npm run generate:types` | Обновить типы после изменения коллекций |

### Изменение полей в админке

1. Измените файл в `src/collections/` или `src/globals/`.
2. Создайте миграцию **с включёнными настройками S3** (иначе в ней не будет колонок для хранилища):
   `S3_ENDPOINT=x S3_BUCKET=x S3_ACCESS_KEY_ID=x S3_SECRET_ACCESS_KEY=x S3_PUBLIC_URL=https://x npm run migrate:create что_изменили`
3. `npm run migrate`, затем `npm run generate:types`.
4. Миграции применяются на сервере сами при запуске.

## Безопасность

- Секреты только в переменных окружения. Файлы `.env*` в git не попадают.
- Публичный доступ на чтение ограничен правилами в `src/access/index.ts`: посетитель видит только записи с включённой публикацией.
- Обращения из формы создаёт только серверный обработчик `/api/inquiries` (антиспам: скрытое поле, не больше 5 обращений в час с одного адреса).
- Вход в админку: блокировка на 10 минут после 5 неверных паролей, сессия 7 дней.
- GraphQL отключён.
